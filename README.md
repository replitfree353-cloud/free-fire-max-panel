# Free Fire Max Headshot Panel

Fully working Free Fire Max Headshot Panel for Android.

## Features
- Headshot Aim Assist
- Auto Aim FOV control
- Smooth Aim
- ESP Player Box / Line / Distance
- Enemy Health Bar
- No Recoil (soft)
- Floating Overlay Panel
- One-tap Headshot toggle

## How to Build APK
1. Install Android Studio (latest)
2. Open this project folder
3. Sync Gradle
4. Build > Build Bundle(s) / APK(s) > Build APK(s)
5. APK will be in `app/build/outputs/apk/debug/app-debug.apk`

## Install on Phone
1. Download the APK from Releases or build it yourself
2. Enable Unknown Sources
3. Install
4. Grant Overlay Permission + Accessibility
5. Open Free Fire Max → Open Panel → Enable Headshot

## Requirements
- Android 8.0+
- Free Fire Max installed
- Root **NOT** required (overlay + accessibility based)

## Panel Controls
- **Headshot ON/OFF** – forces aim to head bone
- **FOV Slider** – aim assist range
- **Smooth** – aim smoothness
- **ESP** – show enemies through walls
- **Close** – hide panel
